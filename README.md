# SFTPPlus Helm chart

Use the published Helm repository at [helm.sftpplus.com](https://helm.sftpplus.com/):

```sh
helm repo add sftpplus https://helm.sftpplus.com/
```

See the [full installation and publishing guide](docs/README.md).

Published chart files live in `docs/` instead of `dist/` because GitHub Pages branch publishing supports the repository root or `/docs` as its source directory.
